LOCAL SETUP
1. Put this folder in C:\xampp\htdocs\lacson_portfolio
2. Start Apache and MySQL in XAMPP.
3. Import lacson_portfolio_db.sql in phpMyAdmin if you want database-backed project entries.
4. Open http://localhost/lacson_portfolio/

NOTE
The portfolio contains built-in fallback project data for DocMatch, Grasya Worldwide, and Lyka Lacson Portfolio, so the project cards still appear even if the database is temporarily unavailable.
